Summary:
There is a aaa config option that allows no authentication:

"aaa authentication login default none"

With "none" configured, there only needs to be a known username to access the Nexus switch. However, all Nexus switches are required to have the username admin defined.

From testing, we found that this means any login attempt is successful if the username exists. The passwords isn't checked. We also see there is no authorization enforced and any command can be run.

There are multiple concerns with this:

1. The "admin" username is well known on the Nexus platform and it can't be disabled.
2. There is no privilege limitation/authorization on commands run.
3. Customers may unintentionally configure TACACS authentication with "none" authentication as the fallback instead of local authentication as the fallback. By doing this, they may not realize that if the TACACS authentication times out, any user who can reach the device, will be able to log into the admin account with no correct password.
