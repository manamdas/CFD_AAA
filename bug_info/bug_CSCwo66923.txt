---Start of Note Titled:  Eng-notes (Created 04/02/2025 07:20:30 Modified 04/02/2025 07:29:41 by anikunna)---
The issue seems to be happening due to the key not being enclosed with pairing " (quotes). 
Keys when configured need to having a starting and closing quotes (paired) or no quotes at all. 
In this case, there is one starting quote and two ending quotes (as shown below)

    radius-server key 7 "b""

If this is properly delimited, this issue will not be encountered.

<B>Symptom:</B>
- The starting-configuration having radius configuration.

switch# show start | inc rad next 2

- The running-configuration missing radius configuration.

switch# show run | inc rad next 2
aaa group server radius Radius_Grdf 
    source-interface Vlan30
copp profile strict

<B>Conditions:</B>
- Going through internal ascii-replay, which can be done after "reload ascii" or might be triggered by a normal upgrade.

- The radius-server key configuration having a double-quotes character preceded by any character or more. Example:

* radius-server host 10.10.10.1 key 7 a"
* radius-server key 7 b"

<B>Workaround:</B>
- Re-apply the radius configuration.
- Changing the key for another one that does not contain the double-quotes character.
