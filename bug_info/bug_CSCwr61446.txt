<B>Symptom:</B>
When TACACS is configured to send on a loopback, SVI, etc (non-mgmt0 interface) interface it will not receive an AV pair from ISE but using the same ISE servers and configurations but sourced from the management VRF using mgmt0 interface it works fine. In the broken scenario the user will always be granted network-operator role regardless of what role they should have.

<B>Conditions:</B>
TACACS configured for non-mgmt0 source interface and vrf

<B>Workaround:</B>
While customer could possibly use mgmt0 this isn't an acceptable workaround in all scenarios

<B>Further Problem Description:</B>
Verified this works without issue in 10.4(4) and the AV pair is received properly on Loopback interfaces.
