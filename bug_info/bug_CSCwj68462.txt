A similar issue has been observed at a customer-site and has been marked as a duplicate of this one. 

<B>Symptom:</B>
When adding "tacacs-server host x.x.x.x key 7 XXXXXXXXX" configuration after connection is already established, the "All servers failed to respond" errors will print for around a minute before the "AAA Daemon" process crashes and saves a core file.

<B>Conditions:</B>
- Nexus 9k running NXOS 10.4(3)
- Already have connection established to tacacs server before configuring "tacacs-server host x.x.x.x key 7 XXXXXXXXX"

<B>Workaround:</B>
None. 10.4.4+ releases have the fix.
