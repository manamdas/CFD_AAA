---Start of Note Titled:  Release-note (Created 08/03/2023 21:35:27 Modified 08/31/2023 22:06:54 by ssavian)---
<B>Symptom:</B>
When upgrading a Nexus 9000 switch from a code where LXC boot mode is not the default mode, to one where it is, using non-disruptive ISSU, radius or tacacs global keys can go missing in the startup config, whereas it will be present in the running-config. This is because in running-config the keys are updated from dme which is not done for startup-config.

<B>Conditions:</B>
Upgrade from earlier N9K release on applicable platforms to later code (10.3.3+ or 10.4.1+) where LXC boot mode is the default. To confirm the boot mode, run "show boot mode", or check for VSUP for TOR switch in the "show module" output.

<B>Workaround:</B>
After upgrade , 'copy r s ' can be done to sync the startup config with the running config
