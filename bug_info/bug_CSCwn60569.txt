---Start of Note Titled:  Release-note (Created 12/23/2024 17:05:58 Modified 01/27/2025 21:04:43 by palshanm)---
<B>Symptom:</B>
A user as network-operator can excute commands that allowed for network-admin when the user was previously network-admin and VSA for the user was removed on radius-server.

<B>Conditions:</B>
Nexus 9000 Series running 10.5(2)F, may be observed in previous releases.
A user was previously authenticated as network-admin with radius via VSA and VSA for that user was removed.

<B>Workaround:</B>
Assigning correct role (network-operator) on radius server
or
Reloading switch. After reload and the user log in, network-operator is assigned for that user and can not excute commands for network-admin

<B>Further Problem Description:</B>
Currently under investigation


---End of Note Titled: Release-note---
