PR Status:Approved
LoC: 145
===================================================================

Pull Request Description
===================================================================
Problem Summary:
ISSU from 7.3.7 => 9.3.11 => 10.4.4
Master-Key is not restored when upgraded to 10.4.4 is done in the above mentioned workflow.

Root Cause Analysis:
The pss_strore() API fails in INFRACONVERT code during the upgrade. The reason being that the PSS data size exceeds its maximum limit during INFRACONVERT conversion.
As a result, ASCII-restore of the config takes place as opposed to BINARY-restore. Since Master-Key is not an entry in running-config display, it cannot be restored by ASCII-restore.

Summary of Code Fix:
The PSS inherits its smaller PSS limits from 7.3.7 - In 10.4.4 INFRACONVERT, we have used pss_convert_layout() (on the inherited PSS) to bring the PSS limits at par with 10.4.4's -

How Has This Been Tested?
Have done SMU based testing for the problem ISSU workflow. More cases to be covered by QA.
