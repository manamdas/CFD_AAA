<B>Symptom:</B>
After performing an upgrade or a reload on impacted code, when the first user tries to ssh into the switch and the device is configured to use TACACS for authentication and authorization, the following error may be seen:

2024 Mar 22 11:17:43.195 switch %TACACS-4-TACACS_WARNING: Problem during name-lookup. Error:-3(temporary failure in name resolution)

This error is only seen for the first login after upgrade or reload and does not apply to this error being seen for subsequent logins.

<B>Conditions:</B>
- Switch is configured with TACACS logging level 4 or lower (4-7):

`show running-config`
logging level tacacs 4

- TACACS is configured and used by AAA:

`show running-config`
tacacs-server key 7 "XXXXXXXX"
ip tacacs source-interface mgmt0
tacacs-server host 192.168.0.1
aaa group server tacacs+ test_group
 server 192.168.0.1
 use-vrf management
aaa accounting default group test_group

- This is a day 1 issue.
- The first user logged into the switch via SSH. Not printed for the second login from the same user or for other users.
- All subsequent reloads or upgrades on impacted code will cause the error to be generated once more for the first user after boot.

<B>Workaround:</B>
None. The error is cosmetic and can be ignored.

<B>Further Problem Description:</B>
This error will only trigger once on boot up.
